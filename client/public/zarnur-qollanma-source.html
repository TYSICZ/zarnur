ZARNUR · API KALIT YARATISH

Provayderda kalitni qanday olish mumkin?

Har bir provayderning menyu nomi o‘zgarishi mumkin. Quyidagi havolalarni faqat rasmiy provayder sahifasi sifatida oching; hisobingizga kirgandan so‘ng “API keys” bo‘limidan yangi kalit yarating.

Google AI Studio

aistudio.google.com/apikey

  1. Google hisobingiz bilan kiring.
  2. “Create API key” tugmasini bosing.
  3. Kerak bo‘lsa loyiha tanlang yoki yangisini yarating.
  4. Yangi kalitni nusxalang va Zarnurdagi model provayderi Google bo‘lsa ishlating.
Groq

console.groq.com/keys

  1. Groq hisobiga kiring yoki ro‘yxatdan o‘ting.
  2. API Keys bo‘limida yangi kalit yarating.
  3. Kalitni yaratilgan zahoti nusxalang; oynani yopgach qayta ko‘rsatmasligi mumkin.
OpenRouter

openrouter.ai/keys

  1. Hisob ochib, Keys bo‘limiga kiring.
  2. “Create Key” orqali kalit yarating va uni nusxalang.
  3. Ro‘yxatdagi OpenRouter modelini tanlang; “free” modellar va limitlar o‘zgarishi mumkin.
Boshqa provayderlar

Zarnur ro‘yxatida ko‘rinadigan boshqa provayder uchun ham shu tartib amal qiladi: rasmiy sayt → hisob → API keys → yangi kalit → Zarnurda aynan shu provayderning modelini tanlang.

Bepul degani cheksiz degani emas. Bepul kvota, ro‘yxatdan o‘tish shartlari, mamlakatlar bo‘yicha mavjudlik va limitlar provayder tomonidan belgilanadi va istalgan vaqtda o‘zgarishi mumkin. Kalit yaratishdan oldin provayderning amaldagi shartlarini tekshiring.

ZARNUR · CHATDAN FOYDALANISH

Chatni boshlash va muammolarni hal qilish

Kalitni ulash

  1. Zarnur chatida kerakli provayder va modelni tanlang.
  2. Shu provayderdan olgan kalitingizni API kalit maydoniga qo‘ying.
  3. Savolingizni yozib, yuborish tugmasini bosing.
  4. Boshqa modelga o‘tsangiz, aynan o‘sha provayderning kaliti kerak bo‘lishi mumkin.

Kalitni himoya qilish

  • Kalitni boshqalarga, jumladan Zarnur administratoriga yubormang.
  • Umumiy yoki begona qurilmada kalit kiritmang.
  • Kalit tasodifan oshkor bo‘lsa, provayder hisobida uni bekor qiling va yangisini yarating.
  • Brauzer yopilganda kalit chat oynasida saqlanmaydi; keyingi safar qayta kiriting.

Ko‘p uchraydigan xatolar

“Invalid API key” yoki 401: provayder mosligini tekshiring, kalit boshida/oxirida bo‘sh joy yo‘qligini ko‘ring; zarur bo‘lsa rasmiy saytdan yangi kalit yarating.
429 yoki limit tugadi: provayder kvotasi to‘lgan bo‘lishi mumkin. Limit yangilanishini kuting yoki o‘zingizda kaliti bor boshqa provayder/model tanlang.
Model topilmadi: faqat Zarnur ro‘yxatida mavjud modelni tanlang. Provayder katalogi va modellar o‘zgarib turishi mumkin.
Kalit maydoni ishlamayapti: HTTPS havolani oching. Oddiy HTTP orqali API kalit yuborish bloklanadi.
Model javobi noto‘g‘ri yoki sekin bo‘lsa, boshqa modelni tanlab ko‘ring. Zarnur turli mustaqil provayderlarning modellariga ulanish imkonini beradi; javob sifati va tezligi tanlangan modelga bog‘liq.

ZARNUR · MAXFIYLIK VA YORDAM

Yordam va maxfiylik

Administrator bilan yozishish

Saytdagi “Yordam” tugmasini bosing va savolingizni yuboring. Xabar Zarnur admin panelidagi yordam chatiga tushadi; administrator javob yozgach, shu oynada ko‘rasiz. Javob darhol kelmasligi mumkin.

API kalit yaratish bo‘yicha yordam kerak bo‘lsa, provayder nomini ayting. Kalitning o‘zini yubormang.

Zarnur qanday ma’lumot saqlaydi?

  • Rozilik bergan brauzerga tasodifiy, anonim tashrif identifikatori beriladi.
  • Tashriflar va Zarnur AI’dan muvaffaqiyatli foydalanish soni hisoblanadi.
  • Faqat umumiy qurilma turi va operatsion tizim aniqlanadi: masalan, telefon · Android yoki telefon · iOS.
  • Aniq telefon modeli, IP-manzil va to‘liq brauzer ma’lumoti Zarnur tashriflar jadvalida saqlanmaydi.
  • Yordam chatiga yuborgan xabaringiz administratorga ko‘rinadi.

API kalitingiz haqida

Kalit Zarnur sahifasidan tanlangan provayderga so‘rov yuborish uchun uzatiladi; Zarnur uni o‘z hisoblarida saqlamaydi. Provayderning o‘zi o‘z shartlariga muvofiq so‘rovlarni qayta ishlaydi. API ishlatilishi provayder limitlari yoki pulli to‘lovlariga olib kelishi mumkin — hisobingizdagi shartlarni tekshirib turing.

Maxfiy ma’lumot yubormang. API kalit, parol, bank karta ma’lumoti, pasport ma’lumoti va maxfiy ish hujjatlarini yordam chatiga yoki AI suhbatiga yozmang.
